# After the Hashtag

A multi-page static research website with a searchable country atlas, timeline slider, mechanism explorer, outcome comparison, research dossier, glossary and quiz, searchable source register, and Markdown/CSV exports.

- Snapshot: 14 October 2026.
- Project context and research limits: PROJECT_CONTEXT.md and downloads/research-paper.md.
- Required footer credit: Made by DEVRAYOG linked to https://v0-devrayog.vercel.app/
- Stack: semantic HTML, CSS and vanilla JavaScript. No user accounts, analytics or personal-data collection.
- Security headers are configured in vercel.json. The site is public by design; do not add credentials or confidential data.
- This is a comparative research synthesis, not original fieldwork or a peer-reviewed publication.

For local preview, serve this directory with a static web server because the atlas and source ledger use client-side JavaScript.
